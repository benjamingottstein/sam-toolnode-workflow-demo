Solace Agent Mesh

Tool node workflow demos

Three event-driven workflows that run entirely on deterministic tool steps — no AI model involved, so each run takes a fraction of a second and costs nothing. Every portal below publishes an event to your broker and shows the event the workflow publishes back.

Sales order sanitizer Removes personal data from a sales order event, validates the result against a contract and republishes it. Shipment enricher Looks up customer and carrier master data over a REST API and republishes the enriched shipment event. Trade settlement correlator Collects three trade events that can arrive in any order and publishes one settlement event when all are in.

Before you start

  1. Copy each .env.example to .env and enter your broker details.
  2. Deploy a demo: cd <demo> && sam config apply --target desktop --env-file .env -m manifest.yaml
  3. Open a portal above, press Connect, enter the same broker details, then publish an event.
